# PitaPerfect - A React & Manifest Application

Welcome to PitaPerfect, a web application for sharing and discovering delicious pita bread recipes. This project is built using React for the frontend and powered entirely by Manifest for the backend.

## Features

- **User Authentication**: Secure sign-up and login for users.
- **Recipe Management**: Create, read, and delete your own pita recipes.
- **Image Uploads**: Add a photo to each recipe to make it look delicious.
- **Community Recipes**: Browse recipes shared by other users.
- **Ownership Policies**: Users can only manage the recipes they have created.
- **Automatic Admin Panel**: A built-in admin interface to manage all users and recipes.

## Tech Stack

- **Backend**: [Manifest](https://www.mnfst.com/) - Handles the database, authentication, file storage, and API generation automatically.
- **Frontend**: [React](https://reactjs.org/) with [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **SDK**: `@mnfst/sdk` for seamless frontend-backend communication.
